Nor is Ron's ~other half~ text editor. It ~is~ will be:

- Modal like [Kakoune](https://kakoune.org) and [Neovim](https://neovim.io), with multiple selections as a primitive
- Extensible like [Neovim](https://github.com/neovim/neovim) / [Emacs](https://www.gnu.org/software/emacs/) with [Janet](https://janet-lang.org/)
- Fast with a minimal core (probably, maybe, it depends)

## Building

Only Linux is currently supported. To build nor you'll need the Odin compiler (version not pinned at this stage). Then run:

```sh
odin run .
```
